# Security policy

Report vulnerabilities privately through [GitHub security advisories](https://github.com/w21180239/claude-code-self-compact/security/advisories/new), not in a public issue.

Relevant reports include a way to make the plugin run a compaction for a session that did not request one, to read or write files outside `~/.claude/self-compact/`, to open a network connection, or to bypass the main-session and interactive-only checks on `compact_now`.

Only the latest release is supported. Expect a first reply within a week.
